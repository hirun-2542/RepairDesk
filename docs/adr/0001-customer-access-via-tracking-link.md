# ลูกค้าเข้าถึงผ่าน Tracking Link แทนบัญชี

ใช้ลิงก์ส่วนตัวที่คาดเดาไม่ได้สำหรับแต่ละใบงาน แทนการสร้างบัญชีลูกค้า เพื่อให้ลูกค้าติดตามสถานะและอนุมัติหรือปฏิเสธราคาได้โดยไม่ต้องสมัครสมาชิก ลิงก์นี้เป็น bearer credential: ผู้ถือมีสิทธิ์ตัดสินใจแทนลูกค้าของใบงานนั้น จึงต้องไม่เผยแพร่ และ Audit ระบุผู้กระทำเป็นลูกค้าที่ใช้ลิงก์ ไม่ยืนยันตัวบุคคล สลิปชำระเงินและข้อมูลภายในร้านไม่ถูกเปิดให้ผู้ถือ Tracking Link ตามขอบเขตที่อนุมัติ
